# homebrew-deck-agent

Homebrew tap for deck-agent, a local agent for presentations built with the `nbg-design` skill.

```sh
brew install biks2013-tools/deck-agent/deck-agent
deck-agent init     # then fill in ~/.tool-agents/deck-agent/.env and run: deck-agent check
```

Releases and documentation: https://github.com/biks2013-tools/deck-agent
